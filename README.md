# 云相册（自建 NAS 相册）

把照片放在自己的硬盘上，手机自动上传，随时随地浏览。
**数据完全自持**：照片就是普通文件夹里的文件，不经过任何第三方云。

[下载免安装版（Windows）](../../releases/latest) · [安装教程](docs/用户手册.md) · [外网访问](docs/外网访问.md)

---

## 这是什么

```
手机 App ──自动补传──▶  你的电脑/NAS 的一个文件夹
                            │
                            ├─ 每分钟重建一次网页相册（缩略图 / 时间轴 / 相册 / 回收站）
                            └─ dufs 提供网页 + WebDAV（局域网 + IPv6 外网）
```

## 特点与优势

**1. 数据完全自持，告别网盘**
照片就是普通文件，放在你自己的硬盘上。想备份就复制，想迁移就拷走。
没有「会员加速」「原画压缩」「停服跑路」这些问题。

**2. 不注册任何账号**
没有用户系统、没有手机号绑定、没有第三方登录。
一个账号密码就是全部——而且这个密码只在你的局域网/家庭网络里用。

**3. Windows 免安装，双击即用**
下载解压后：`1_配置向导.exe` 回答 4 个问题 → `2_启动相册.exe` 后台运行。
内置 Python 运行时、Pillow、ffmpeg（视频封面），**什么都不用装**。

**4. 手机自动补传**
打开 App 就把新照片/视频传上来，支持 HEIC，原文件名不改动。

**5. 网页相册功能齐全**
时间轴 / 相册分组 / 搜索 / 多选批量 / 回收站（30 天可还原）/ 新建相册 / 拖动排序。

**6. 外网访问零成本**
只要宽带或手机流量有 IPv6（现在很普及），直连就能访问，
不需要公网 IPv4、不需要买域名、不需要开路由器端口。
（文档里同时写清了 IPv6 直连的隐私风险与缓解办法。）

**7. 代码量小，可读可改**
核心是一个 Python 单文件生成器 + 一个安卓 App，
没有框架、没有数据库，想改哪里直接看哪里。

## 明确不做什么（诚实声明）

- **无多用户/权限分级**：一个账号 = 全部权限，适合家庭自用
- **无端到端加密**：外网走明文 http（文档教了怎么评估风险）
- **无在线编辑/人脸识别**：相册是纯静态页，快且简单
- **不自动做任何云备份**

## 快速开始（Windows，约 5 分钟）

```
1. 从 Releases 下载「云相册_免安装版.zip」并解压
2. 双击「1_配置向导.exe」→ 选照片目录、设端口、设账号密码
3. 双击「2_启动相册.exe」（后台运行，无窗口）
4. 手机装 apk\我的相册.apk → 填向导给出的地址 → 完成
```

详细图文：[docs/用户手册.md](docs/用户手册.md)

## 目录结构

```
photos/                      你选的照片根目录
├── 05_收件箱/手机相册/       手机上传的照片（按手机相册名分文件夹）
```

## 常见问题

**手机打不开？**
先在电脑浏览器里开 `http://电脑IP:8081` 确认服务正常；
打不开查服务窗口；能开但手机不行，九成是防火墙——`诊断.exe` 会给出具体提示。

**为什么外网要用 IPv6？**
IPv4 公网地址现在很难拿到，IPv6 普及得多。
IPv6 地址会变，所以 App 的地址可能需要偶尔更新（`地址.txt` 会自动记录最新值）。
介意的话可以用 Tailscale / Cloudflare Tunnel，文档里有对比。

**照片会被压缩吗？**
不会。上传保持原文件，网页只生成缩略图。

# 用户手册：两种用法（家里 / 外面）

装好之后，你有两种用法，**用的是同一个 App、同一台电脑**，只是手机上填的地址不同。

| 用法 | 手机在哪 | 填什么地址 |
|---|---|---|
| **内网** | 连着家里的 Wi-Fi | `http://192.168.x.x:8081` |
| **外网** | 用 4G/5G、或公司 Wi-Fi | `http://[240e:xxxx:...]:8081` |

> **外网必须用 IPv6。** 没有公网 IPv6 的宽带，外网这条走不通，只能在家里用。

---

## 一、内网（装完就能用）

1. 电脑双击 `启动相册服务.cmd`，窗口里会打印
   ```
   [服务] 手机/电脑打开：
           http://192.168.1.10:8081/           （局域网）
   ```
2. 手机连同一个 Wi-Fi
3. App 首屏填 `http://192.168.1.10:8081`（**带 http://**）

---

## 二、外网（要 IPv6）

### 前提检查

电脑上双击 `外网访问.cmd`，看有没有「公网 IPv6：240e:…」。

- 有 → 继续
- 没有 → 说明宽带/路由器没开 IPv6，先到路由器里打开 IPv6（不同品牌叫法不同），或者这条路就用不了

### 手机怎么填

服务启动时窗口里会多打印一行：

```
        http://[240e:8a00:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx]:8081/   （外网，手机用流量试）
```

**方括号不能少。** 手机 App 里把地址改成这一行。

### 注意：地址会变

运营商隔一段时间会换 IPv6 前缀（重启路由器时最常见）。变了之后：

- 重新看服务窗口打印的那一行
- App 里把地址改掉

> 想稳定的话，需要配 DDNS（把域名自动指向新地址），属于进阶操作，不在默认范围内。

---

## 三、隐私与安全风险（务必看清）

用外网 = 把你电脑上的一个端口**暴露在公网上**。风险是真实的，不是吓唬：

1. **传输是明文 http**
   同一个网络里的人（公共 Wi-Fi、公司网络）可以抓到你的照片和密码。
   → 别在公共 Wi-Fi 下用；只在家里/自己的流量上用。

2. **端口会被扫描**
   公网 IP 一直在被机器扫描，IPv6 地址也不例外（前缀虽然长，仍然会被扫到）。
   → **密码至少 12 位**，不要用 `123456`、`admin`、生日。

3. **没有失败次数限制**
   理论上可以被暴力试密码。密码够长就基本试不出来。

4. **任何人拿到地址 + 密码，就能看你全部照片**
   这个项目没有"只读访客"之类的权限分级，一个账号 = 全部权限。

5. **你的 IPv6 地址等于暴露了"这台机器在哪个网络"**
   知道地址的人可以判断你的运营商和大致地区。

### 想更安全，可以

- 只在需要用的时候才开服务，用完关掉窗口
- 用完之后在路由器/防火墙里关掉这个端口
- 密码用随机长串（配置向导里自己生成一个，记在备忘录里）

### 不想暴露公网？

那就只用内网（家里 Wi-Fi）。这个项目不依赖外网也能正常用。

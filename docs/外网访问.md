# 外网访问（在外面也能看）

默认只在家里的 Wi-Fi 能用。想在外面（4G/公司）也能看，有三条路，**选一条就行**。

先双击 `外网访问.cmd`，它会直接告诉你这台电脑能用哪条、手机上该填什么地址。

---

## ① IPv6 直连（免费、不用装东西）

现在的宽带大多有 IPv6。

1. 双击 `外网访问.cmd`，如果显示「公网 IPv6：240e:...」，就能用
2. 手机地址填：`http://[240e:xxxx:...]:8081`（方括号要有）
3. 手机所在的 4G/5G 一般也支持 IPv6

**缺点**：这个地址会变（运营商隔几天换一次），变了就得重新填。
想稳定要配 DDNS（把域名自动指向新地址）。

---

## ② Tailscale（最省事，推荐给不想折腾的人）

不管你家宽带有没有公网 IP，都能用。

1. 电脑装 Tailscale：<https://tailscale.com/download>，注册登录
2. 手机装 Tailscale（应用商店有），登录**同一个账号**
3. 双击 `外网访问.cmd`，它会显示类似 `100.101.102.103` 的地址
4. 手机 App 里填：`http://100.101.102.103:8081`

之后不管在家里还是外面，都能用这个地址。
**不用改路由器，不用公网 IP，不用域名。**

---

## ③ Cloudflare Tunnel（要一个域名，最正规）

有自己的域名（几十块一年）就用这个，能拿到 https。

1. 域名托管到 Cloudflare
2. 电脑装 cloudflared：<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>
3. 登录并建隧道：
   ```
   cloudflared tunnel login
   cloudflared tunnel create album
   cloudflared tunnel route dns album album.你的域名.com
   cloudflared tunnel run --url http://localhost:8081 album
   ```
4. 手机 App 填：`https://album.你的域名.com`

隧道是**主动往外连**的，所以不需要公网 IP、不用开端口，运营商封了 80/443 也能用。

---

## 该选哪个

| 你的情况 | 选 |
|---|---|
| 只想快点在外面也能看 | ① IPv6（有的话） |
| 不懂网络 / 宽带没有公网 IP | ② Tailscale |
| 有域名，想要稳定 + https | ③ Cloudflare Tunnel |

---

## 安全提醒

- 放公网前，**密码至少 12 位**，别用 admin/123456
- 只想自己家人用：② Tailscale 最安全（外人根本连不到你的端口）
- ③ 用 https，密码不会明文传输
- ① 是明文 http，公共 Wi-Fi 下别用

# Windows 安装（图文步骤）

> 全程大约 5 分钟。只需要做一次。

## 0. 准备

- 一台常开的 Windows 电脑（做「NAS」的那台）
- 手机和电脑连**同一个 Wi-Fi**

## 1. 装 Python

1. 打开 <https://www.python.org/downloads/> 下载 Python 3.10 以上
2. 安装时**务必勾选** `Add python.exe to PATH`
3. 装完在「命令提示符」里输入 `python --version`，能看到版本号就对了

## 2. 装 ffmpeg（可选，视频封面用）

1. 下载 <https://www.gyan.dev/ffmpeg/builds/> 的 release 包
2. 解压到比如 `C:\ffmpeg`，把 `C:\ffmpeg\bin` 加进系统 PATH
3. 命令行输入 `ffmpeg -version` 验证

> 不装也能用，只是视频没有封面图。

## 3. 跑配置向导

双击 `配置向导.cmd`，依次回答：

```
照片存放的文件夹: D:\照片          ← 你自己的照片目录，回车用默认
网页端口: 8081                     ← 回车即可；被占用会提示换
账号: nas
密码: 至少6位
```

结束时屏幕会打印**手机要填的那三行**，记下来（也可以随时再跑一次向导查看）。

## 4. 启动服务

双击 `启动相册服务.cmd`，看到：

```
[生成] 完成：N 个相册，M 项媒体
[服务] 网页地址 http://192.168.x.x:8081/
```

这个窗口**不要关**，关了服务就停了。

第一次启动时 Windows 防火墙会弹窗，选**允许访问**（专用网络勾上）。

## 5. 手机装 App

1. 把 `apk\我的相册.apk` 传到手机（微信/QQ/数据线都行）
2. 安装时允许「未知来源」
3. 打开 App，第一次会弹窗，填第 3 步打印的三行
4. 点「测试连接」→ 成功 → 点「连接」

进去后就能看到相册了；手机里以后新拍的照片会自动传上去。

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 手机点连接提示「连不上」 | ① 不在同一 Wi-Fi ② 防火墙拦了（见下）③ IP 填错 |
| 防火墙怎么放行 | 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾上 Python（专用+公用） |
| 电脑重启后 IP 变了 | 路由器里给电脑做「IP 绑定/MAC 绑定」，或在 Windows 里设静态 IP |
| 想让它开机自启 | 把 `启动相册服务.cmd` 的快捷方式放进 `shell:startup` |
| 端口被占用 | 重跑向导换一个端口，手机上也改 |

## 7. 想让电脑外网也能看

见 `外网访问.md`。**先确认你的宽带有没有公网 IP**，没有的话用内网穿透（Tailscale 最简单）。
